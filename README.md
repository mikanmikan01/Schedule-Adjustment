# 自動スケジュール管理システム (GAS)

## 概要
13名規模のプロジェクト運営における、スケジュール調整および集計プロセスを完全自動化するGoogle Apps Script（GAS）システムです。手作業での予定すり合わせに伴う時間的コストと、確認漏れなどのヒューマンエラーを解消するために構築しました。

## 主要機能と技術的工夫
* **Calendar APIによる動的枠生成:**
  日本の祝日カレンダー（Google Calendar API）からイベントを取得し、平日（夜枠のみ）と土日祝（昼夜の複数枠）でスプレッドシートの回答枠を自動的に出し分けます。
* **最適日程の自動サマリー抽出:**
  メンバーの入力（〇, △, ✕）をリアルタイムで集計し、`QUERY`関数を用いて「〇の数が多い順 ＞ 〇+△の数が多い順」の複合条件でソート。参加率トップ10の日程をシート右側に自動出力し、意思決定の工数をゼロにしました。
* **フールプルーフとUX最適化:**
  入力規則（プルダウン制限）と条件付き書式（回答に応じた色分け）を設定し、ITリテラシーを問わず直感的に操作できるUIを実現しています。

## 技術スタックと開発アプローチ
* **使用技術:** Google Apps Script (JavaScript), Google Sheets API, Google Calendar API
* **AIを活用したモダンな開発プロセス:**
  開発スピードを最大化するため、ベースのコード生成に生成AIを活用しています。自身はシステムの要件定義，設計に注力し、出力されたコードに対する「配列参照ズレなどのロジックバグの修正（デバッグ）」や「実運用に向けた最適化」を行いました。
